คู่มือการใช้งาน ZENTRA Safety AI System

ระบบตรวจจับความปลอดภัยในพื้นที่ทำงานด้วย AI  ·  สำหรับ Windows 11 (64-bit)

สารบัญ
  1. สิ่งที่เครื่องต้องมี
  2. การติดตั้ง
  3. เปิดใช้งานครั้งแรก
  4. วิธีออกจากโปรแกรม (สำคัญ)
  5. การตั้งค่ากล้อง
  6. การตั้งค่าโซนพื้นที่อันตราย
  7. ความสามารถของระบบ
  8. การแจ้งเตือนผ่าน LINE และ PDPA
  9. ปัญหาที่พบบ่อย
  10. การถอนการติดตั้ง

1สิ่งที่เครื่องต้องมี

รายการความต้องการ
ระบบปฏิบัติการWindows 11 (64-bit) เท่านั้น
Pythonไม่ต้องเตรียมเอง — ตัวติดตั้งลง Python 3.11 ให้อัตโนมัติ
(ระบบใช้ได้กับรุ่น 3.11 เท่านั้น ตัวติดตั้งจึงลงรุ่นนี้ให้โดยเฉพาะ
ถ้าเครื่องมี Python รุ่นอื่นอยู่แล้วก็ไม่กระทบกัน)
RAM8 GB ขึ้นไป
พื้นที่ว่างประมาณ 3 GB (ถ้ามีการ์ดจอ NVIDIA เผื่อไว้ 8 GB)
กล้องกล้อง USB (webcam) หรือกล้อง IP ที่รองรับ RTSP
หรือจะใช้ไฟล์วิดีโอที่บันทึกไว้ก็ได้
การ์ดจอไม่จำเป็น — ถ้ามี NVIDIA ระบบจะใช้อัตโนมัติและเร็วขึ้นมาก
ถ้าไม่มีจะใช้ CPU ซึ่งช้ากว่าแต่ยังใช้งานได้
อินเทอร์เน็ตต้องมี เฉพาะตอนติดตั้งครั้งแรก
หลังติดตั้งเสร็จใช้งานแบบออฟไลน์ได้ (ยกเว้นถ้าเปิดแจ้งเตือน LINE)
ไม่ต้องเตรียมอะไรเลยนอกจากเครื่อง Windows 11 กับอินเทอร์เน็ต ทุกอย่างที่ระบบต้องใช้ (Python 3.11 และ WebView2 ตัวแสดงผลหน้าจอ) ติดมากับไฟล์ ZIP แล้ว INSTALL.bat จะตรวจเองว่าเครื่องขาดอะไร แล้วลงให้เฉพาะตัวที่ขาด ถ้ามีอยู่แล้วจะข้ามไป ไม่ไปยุ่งกับของเดิมในเครื่อง

2การติดตั้ง

  1. แตกไฟล์ ZIP แล้วย้ายโฟลเดอร์ไปไว้ที่ C:\ZENTRA
    อย่าวางไว้ใน Downloads หรือ Desktop Windows มีข้อจำกัดความยาวชื่อ path ที่ 260 ตัวอักษร ถ้า path ยาวเกินไป การติดตั้งจะพังแบบหาสาเหตุยาก วางที่ C:\ZENTRA ปลอดภัยที่สุด
  2. ดับเบิลคลิก INSTALL.bat
    ตัวติดตั้งจะทำให้อัตโนมัติทั้งหมด 7 ขั้นตอน: ลง Python 3.11 ให้ถ้าไม่มี → เตรียมพื้นที่ติดตั้ง → ลง WebView2 ให้ถ้าไม่มี → ตั้งค่าเริ่มต้นและตรวจไฟล์โมเดล → ตรวจหาการ์ดจอ NVIDIA เอง → ดาวน์โหลดไลบรารี → ทดสอบโหลดโมเดล AI จริง
    ใช้เวลาประมาณ 10–20 นาที ต้องต่ออินเทอร์เน็ตไว้ตลอด ระบบจะดาวน์โหลดประมาณ 500 MB (หรือประมาณ 2.5 GB ถ้าเครื่องมีการ์ดจอ NVIDIA) ระหว่างนี้จะเห็นข้อความวิ่งเยอะ ๆ เป็นเรื่องปกติ
    ไม่ต้องกดอะไรระหว่างติดตั้ง ตอนลง Python จะไม่มีหน้าต่างเด้งขึ้นมาให้กด (ลงแบบเงียบเฉพาะผู้ใช้นี้ จึงไม่ต้องใช้สิทธิ์แอดมิน) แค่รอจนขึ้นว่า "ติดตั้งสำเร็จ!"
  3. รอจนขึ้นข้อความ “ติดตั้งสำเร็จ!”
    ถ้าขึ้นข้อความสีแดงว่า [ผิดพลาด] ให้อ่านข้อความนั้น — บอกวิธีแก้ไว้แล้ว ส่วนใหญ่แค่รัน INSTALL.bat ใหม่อีกครั้งก็ผ่าน
รัน INSTALL.bat ซ้ำได้เสมอ ไม่เสียหาย ถ้าอินเทอร์เน็ตหลุดกลางทาง หรือติดตั้งไม่จบ ให้กดรันใหม่ได้เลย ของที่โหลดไปแล้วจะไม่โหลดซ้ำ และ การตั้งค่าที่คุณแก้ไว้จะไม่ถูกทับ

3เปิดใช้งานครั้งแรก

เปิดโปรแกรมด้วยการดับเบิลคลิก   ZENTRA.bat

ครั้งต่อ ๆ ไปกดแค่ ZENTRA.bat ไฟล์เดียวพอ ไม่ต้องติดตั้งซ้ำอีก

สิ่งที่จะเกิดขึ้น

  1. มีหน้าต่างสีดำ (console) เปิดขึ้นมาก่อน — บอกว่าใช้โหมด CPU หรือ NVIDIA
    ห้ามปิดหน้าต่างสีดำนี้ หน้าต่างนี้คือตัวรันโปรแกรมจริง ๆ ปิดเมื่อไหร่โปรแกรมดับทันที และถ้ามีปัญหาอะไร ข้อความบอกสาเหตุจะขึ้นตรงนี้ ย่อเก็บไว้ได้ แต่อย่าปิด
  2. จากนั้นหน้าต่างโปรแกรมจะเปิดเต็มจอ ขึ้นหน้า splash ของ ZENTRA
  3. ครั้งแรกจะช้าเป็นพิเศษ เพราะต้องโหลดโมเดล AI เข้าหน่วยความจำ รอสักครู่ ยังไม่ค้าง

สำคัญ: ครั้งแรกจะยังไม่มีโมเดลใดทำงาน

สถานะโมเดลบนแดชบอร์ดจะเป็นสีเทาทั้งหมด — ไม่ใช่อาการเสีย ระบบตั้งใจไม่เปิดโมเดลใดให้อัตโนมัติ เพราะกล้องแต่ละตัวมีหน้าที่ต่างกัน (บางจุดต้องตรวจหมวกนิรภัย บางจุดแค่กันคนเข้าเขตอันตราย) คุณต้องเลือกเองว่ากล้องแต่ละตัวจะให้ตรวจอะไร ระบบจะได้ไม่แจ้งเตือนเรื่องที่คุณไม่ได้ต้องการ

วิธีเปิดโมเดล:

  1. ไปที่หน้า “กล้อง”
  2. กดปุ่มตั้งค่าหน้าที่ (ไอคอนสไลเดอร์) ของกล้องที่ต้องการ
  3. ติ๊กเลือกสิ่งที่ต้องการให้ตรวจ: อุปกรณ์นิรภัย (PPE) / พื้นที่หวงห้าม / การล้ม
  4. บันทึก แล้วกลับมาดูแดชบอร์ด — สถานะจะเปลี่ยนเป็นสีเขียวเฉพาะตัวที่เลือก
เลือกเท่าที่จำเป็น จะเร็วกว่า ยิ่งเปิดหลายโมเดล เครื่องยิ่งทำงานหนักและภาพยิ่งกระตุก โดยเฉพาะบนเครื่องที่ไม่มีการ์ดจอ NVIDIA — เปิดเฉพาะที่ต้องใช้จริงจะลื่นกว่ามาก

4วิธีออกจากโปรแกรม

อ่านหัวข้อนี้ก่อนเปิดโปรแกรมครั้งแรก ZENTRA เปิดแบบเต็มจอ (kiosk) — ตั้งใจออกแบบให้พนักงานหน้างานปิดไม่ได้โดยบังเอิญ จึงไม่มีปุ่ม X และไม่มีแถบชื่อหน้าต่างของ Windows ถ้าไม่รู้วิธีออกจะรู้สึกเหมือนเครื่องค้าง

ออกจากโปรแกรมได้ 2 วิธี:

วิธีทำอย่างไร
ปุ่มในโปรแกรมกดปุ่มออกที่ มุมขวาบน ของหน้าจอโปรแกรม (วิธีปกติ)
F11ออกจากโหมดเต็มจอ จะได้หน้าต่างธรรมดาที่มีปุ่ม X ให้กดปิด
ปิดแล้วอย่าเพิ่งรีบเปิดใหม่ ตอนปิด ระบบต้องคืนกล้องและส่งการแจ้งเตือนที่ค้างอยู่ให้เสร็จก่อน ใช้เวลาไม่กี่วินาที รอให้หน้าต่างสีดำปิดไปเองจนสุด แล้วค่อยเปิดใหม่

5การตั้งค่ากล้อง

เลือกแหล่งภาพได้จากหน้า “แหล่งสัญญาณ / กล้อง” ในตัวโปรแกรม

แหล่งภาพวิธีใช้
กล้อง USBเสียบกล้องก่อนเปิดโปรแกรม แล้วเลือกกล้องในหน้าตั้งค่า
ถ้ามีหลายตัว ให้ลองเปลี่ยนหมายเลขกล้อง (0, 1, 2 …)
กล้อง IP / RTSPใส่ URL เช่น rtsp://user:pass@192.168.1.50:554/stream1
ไฟล์วิดีโอกดปุ่มเลือกไฟล์ แล้วเลือกไฟล์ .mp4 / .avi / .mov
เหมาะกับการทดลองใช้งานก่อนติดตั้งกล้องจริง
มุมกล้องมีผลกับความแม่นยำมาก ติดกล้องให้เห็นคนเต็มตัว ตั้งแต่ศีรษะถึงเท้า ระบบตรวจหมวกนิรภัยและการล้ม จากสัดส่วนร่างกาย ถ้าเห็นแค่ครึ่งตัวหรือมุมกดจากด้านบนมากเกินไป ความแม่นยำจะตกลง

6การตั้งค่าโซนพื้นที่อันตราย

ไปที่หน้า “โซน / Zone Editor” เพื่อวาดพื้นที่ที่ไม่อนุญาตให้คนเข้า (เช่น รอบเครื่องจักร ปากบ่อ พื้นที่กำลังก่อสร้าง) เมื่อมีคนเข้าไปในโซน ระบบจะแจ้งเตือน

  1. เปิดหน้าโซน จะเห็นภาพจากกล้องเป็นพื้นหลัง
  2. คลิกไปตามมุมของพื้นที่ที่ต้องการ ทีละจุด จนได้รูปหลายเหลี่ยมปิดล้อมพื้นที่นั้น
  3. กดบันทึก — โซนจะถูกเก็บไว้และใช้งานทันที ไม่ต้องเปิดโปรแกรมใหม่
โซนผูกกับมุมกล้อง ถ้าขยับหรือหันกล้อง ต้องกลับมาวาดโซนใหม่ เพราะพิกัดที่วาดไว้อ้างอิงกับภาพเดิม

7ความสามารถของระบบ

ระบบตรวจจับอะไร
อุปกรณ์นิรภัย (PPE)ตรวจว่าคนในภาพสวมหมวกนิรภัยและเสื้อสะท้อนแสงครบหรือไม่
ถ้าไม่ครบจะแจ้งเตือน
โซนอันตรายตรวจว่ามีคนเข้าไปในพื้นที่ที่วาดโซนไว้หรือไม่
การล้มตรวจจับท่าทางคนล้มจากการเคลื่อนไหวย้อนหลังประมาณ 1 วินาที
รองรับหลายคนพร้อมกัน

หน้า แดชบอร์ด แสดงสถานะสด ๆ ของทั้ง 3 ระบบพร้อมภาพจากกล้อง ส่วนหน้า ประวัติ เก็บเหตุการณ์ย้อนหลังพร้อมภาพ ณ วินาทีที่ตรวจพบ และส่งออกรายงานได้

สีสถานะบนแดชบอร์ด เทา = ยังไม่เริ่มทำงาน · เขียว = ทำงานปกติ · เหลือง/แดง = พบเหตุการณ์ ถ้าเปิดโปรแกรมแล้วยังเป็นสีเทาอยู่ แปลว่ายังไม่ได้เลือกแหล่งภาพ หรือระบบยังเริ่มไม่สำเร็จ

8การแจ้งเตือนผ่าน LINE และ PDPA

ระบบส่งการแจ้งเตือนเข้ากลุ่ม LINE ได้ (ต้องต่ออินเทอร์เน็ต) ตั้งค่าโดยแก้ไฟล์ backend\.env เปิดด้วย Notepad ได้เลย

LINE_OA_CHANNEL_ACCESS_TOKEN= ← token ของ LINE Official Account
LINE_OA_GROUP_SUPERVISOR= ← กลุ่มหัวหน้างาน
LINE_OA_GROUP_SAFETY= ← กลุ่มเจ้าหน้าที่ความปลอดภัย
LINE_OA_GROUP_EMERGENCY= ← กลุ่มเหตุฉุกเฉิน
LINE_UPLOAD_IMAGES=false ← ส่งภาพไปด้วยหรือไม่
ข้อควรระวังเรื่อง PDPA (ข้อมูลส่วนบุคคล) ค่าเริ่มต้น LINE_UPLOAD_IMAGES=false คือ ไม่ส่งภาพ ส่งแต่ข้อความ — ตั้งใจตั้งไว้แบบนี้ เพราะภาพเหตุการณ์มีใบหน้าพนักงานซึ่งเป็นข้อมูลส่วนบุคคล ถ้าจะเปลี่ยนเป็น true ต้องแจ้งพนักงานและขอความยินยอมตามกฎหมาย PDPA ก่อน

เช่นเดียวกัน ภาพเหตุการณ์ทั้งหมดถูกเก็บไว้ในโฟลเดอร์ data\ บนเครื่องนี้ ถ้าจะส่งต่อหรือคัดลอกโฟลเดอร์นี้ ให้ระวังเรื่องข้อมูลส่วนบุคคลด้วย

แก้ไฟล์ backend\.env เสร็จแล้วต้องปิดแล้วเปิดโปรแกรมใหม่ค่าถึงจะมีผล
