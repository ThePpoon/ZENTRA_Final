===============================================================
  ZENTRA Safety AI System
  ระบบตรวจจับความปลอดภัยในโรงงานด้วย AI
===============================================================

  วิธีเริ่มใช้งาน - 3 ขั้นตอน


  1) โหลดโปรเจกต์จาก GitHub

     กดปุ่มเขียว "Code" แล้วเลือก "Download ZIP"
     ไฟล์ประมาณ 85 MB (มีโมเดล AI มาให้ครบแล้ว ไม่ต้องโหลดเพิ่ม)


  2) แตกไฟล์ ZIP

     คลิกขวาที่ไฟล์ ZIP -> Properties
       ถ้าเห็นช่อง "Unblock" ที่มุมล่างขวา ให้ติ๊ก แล้วกด OK
       (Windows กันไฟล์ที่โหลดจากเน็ตไว้ ขั้นนี้คือบอกว่าเราไว้ใจ)

     แล้วคลิกขวาที่ไฟล์ ZIP อีกครั้ง -> Extract All

     * วางไว้ที่ไหนก็ได้ - Desktop, Downloads, ไดรฟ์ D: ได้หมด
     * ถ้าลึกเกินไปจริง ๆ ตัวติดตั้งจะบอกเองพร้อมบอกวิธีแก้


  3) เข้าไปในโฟลเดอร์ที่แตกออกมา แล้วดับเบิลคลิก  ZENTRA.bat

     ครั้งแรก  : ติดตั้งให้เองอัตโนมัติ ใช้เน็ต ประมาณ 10-20 นาที
                 (ลง Python ให้ด้วยถ้าเครื่องยังไม่มี ไม่ต้องทำเอง)
     ครั้งต่อไป: กดไฟล์เดิม เปิดโปรแกรมได้ทันที

     ถ้า Windows ขึ้นเตือนว่า "Windows protected your PC"
     ให้กด "More info" แล้วกด "Run anyway"


  *** เข้าโปรแกรมครั้งแรก: ต้องเลือกโมเดลก่อน ***
  ตอนเริ่มต้นจะยังไม่มีโมเดลใดทำงาน (ตั้งใจให้เป็นแบบนี้)
  ให้ไปที่หน้า "กล้อง" แล้วเลือกว่าจะให้กล้องตัวไหนตรวจอะไรบ้าง
  (อุปกรณ์นิรภัย / พื้นที่หวงห้าม / การล้ม)


  คู่มือการใช้งานฉบับเต็ม
  -> ดับเบิลคลิกไฟล์  MANUAL_TH.html  (เปิดในเบราว์เซอร์)

  สำหรับนักพัฒนา - อยากรู้ว่าไฟล์ไหนทำอะไร
  -> เปิดโฟลเดอร์  docs\  แล้วอ่าน  STRUCTURE.md


  สิ่งที่เครื่องต้องมี
  - Windows 11 (64-bit)
  - RAM 8GB ขึ้นไป
  - พื้นที่ว่างในดิสก์ 8GB ขึ้นไป
  - กล้อง USB หรือกล้อง IP (RTSP) หรือจะใช้ไฟล์วิดีโอก็ได้
  - การ์ดจอ NVIDIA (ถ้ามีจะเร็วขึ้นมาก แต่ไม่มีก็ใช้ได้)
  - อินเทอร์เน็ต (เฉพาะตอนติดตั้งครั้งแรก หลังจากนั้นใช้ออฟไลน์ได้)

  ไม่ต้องลง Python เองนะครับ ตัวติดตั้งลงให้อัตโนมัติ


  ติดตั้งค้างกลางทาง / อยากซ่อมระบบ
  - ดับเบิลคลิก ZENTRA.bat ใหม่อีกครั้งได้เลย ปลอดภัย
    ของที่ติดตั้งไปแล้วจะไม่ทำซ้ำ เริ่มต่อจากจุดที่ค้างไว้
  - ถ้าอยากบังคับให้ตรวจทุกขั้นตอนใหม่ ให้กด INSTALL.bat แทน


  ออกจากโปรแกรมยังไง?
  โปรแกรมเปิดแบบเต็มจอ ไม่มีปุ่ม X ที่มุมขวาบนของ Windows
  ให้กดปุ่มออกที่อยู่ในตัวโปรแกรม (มุมขวาบน) หรือกด F11
